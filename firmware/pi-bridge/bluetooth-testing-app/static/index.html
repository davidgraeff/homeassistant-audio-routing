A2DP codec

The phone picks the codec from what this Pi advertises, so there is no direct “use SBC now” command. Two levers, and only the ones this box really offers are enabled below.

1 · Switch device profile checking…

Renegotiates in place — no restart, no reconnect.

2 · Allowed codec set unrestricted

bluez5.codecs is an allow-list: tick what the Pi may advertise, and the phone can only choose from those. Excluding a codec means leaving it unticked — untick aptx and aptx_hd to force a fallback to AAC/SBC.

WirePlumber reads this only at startup, so Apply & renegotiate does the whole safe sequence: write → disconnect the phone → restart WirePlumber → reconnect. That order matters — restarting WirePlumber while a phone is connected orphans the bridge's loopback, so the restart happens with nothing connected. Write file only leaves it for the next reconnect. Ticking nothing is rejected: an empty allow-list would stop audio entirely.
